# 道具最终提示词（单张产品图 · 白底单品）

生成的是一张**单视角产品图** —— **不是三联板、不是多角度拼图**：

| 项 | 内容 | 治什么 |
|---|---|---|
| **视角** | **扁平道具**（纸张 / 证件 / 照片）= **正俯视平铺，平摊占满画面**；**立体道具** = **微俯视 3/4 正面** | **文字与比例的唯一清晰来源**，字占满画面 |
| **背景** | 纯白衬底，不带场景感、不带情节暗示、不带装饰 | 背景不承载叙事 |
| **主体** | **画面里只有这一个道具** | 防污染 |

## 🔴🔴 为什么改成单张（2026-10-10 用户拍板，实测根因）

**旧版是三联板**（横向三格：正面 / 3/4 侧视 / 背面，拼在一张图里）。**实测翻车**（sb302 报到单）：

- **道具上的字与参考图不符**；而**同一段分镜里、场景参考图上的标语字一直很准** —— **差别就在：场景图是单一视角，道具图是三联板**。
- **三联板把「同一件道具」画成「三个不同的东西」** → 模型**分不清哪块是标准视角**（很可能拿了背面那块当参考），所以正面画出来不对、背面反而"差不多"。
- **每格只占整图约 1/3 像素** → 字更糊，更画不准。
- **用户口径**：道具上的文字**入画必须准**；**其他时候只要形状、大小正确**即可 → **单视角 + 字占满画面**是满足"字准"的前提。
- **代价**：翻到背面的镜头没有参考图（按用户口径可接受 —— 背面本来也没字）。

四条硬性要求：
1. **物品各部分比例准确** —— 不要夸张、变形或风格化拉伸，道具的相对尺寸关系必须真实
2. **边缘完整** —— 道具整体完整入镜，四周留白，任何部分都不得被画面边缘裁切
3. **背景不承载任何叙事内容** —— 纯白背景只是衬底，不带场景感、不带情节暗示、不带装饰元素
4. **画面里只有这一个道具** —— 除纯白背景与它自身的轻淡阴影外，**不得出现任何其他东西**：人物、**手（任何形式的持握 / 手指 / 手掌 / 手臂）**、其他物品、包装、底座、展示架、场景环境。**持握状态由视频自己生成，绝不由参考图给出**

## 输出结构（按此顺序组装，语言跟随会话语言指令）

```
单品产品图，纯白背景，无边框、无标注文字、无箭头、无编号，画面中不出现任何额外文字：
[视角：扁平道具写"正俯视平铺，平摊占满画面"；立体道具写"微俯视 3/4 正面"]，
[道具名 + 材质/颜色/形状/大小 + 新旧程度与磨损细节]，
[若有文字：按「画面内文字」规则逐字写],
物品各部分比例准确，孤立放置在纯白背景上，居中完整入镜，边缘完整无裁切；
道具表面的文字、表格线、印章占满画面、清晰锐利、笔画完整可辨（这是本图的头号目标）；
柔和均匀的影棚光，轻淡阴影，高细节
```

## 画面内文字（硬性规则）

**道具本体上的文字必须逐字写出**——包装正面字、标签、书名、印章字样、刻字、铭牌数字。不写具体文字、只说"表面有文字"，模型必然乱码。

- **有字**：用引号把原文框住，写明位置（如 `包装正面印着"云南白药"四个字`、`封皮上竖排写着"春秋"二字`）
  - **只写短的**：中文 ≤6 字、英文/数字 ≤2 个词
  - 文字来源**逐字照抄**资产 `name`／`description` 里已有的文字，**禁止改写、禁止自己编**；`description` 没写但道具必然有字（如书名）→ 按小说情景给出最简写法
- **无字**：明确写「道具表面没有任何文字」，**不许留白让模型自由发挥**
- **禁止**："表面有一些文字" / "包装上有汉字" 这类不给具体文字的写法
- **纸张 / 证件类（单据、证件、信纸、报纸、书页、照片）另有三条硬性**：
  - **内容要编全**：标题（大字）+ 正文 2~4 行 + 落款（人名 / 日期）+ 印章（章内的字），**各成一组、逐字写死**。例：`纸面竖排写着"报到证"三个大字；下方正文三行分别写着"林巧""红星机械厂""二车间钳工"；右下角落款"三月十七日"；一枚红色圆章，章内写着"红星机械厂"`——纸面很大，只写一个标题会显得空旷简陋，更容易被模型留白
  - **🔴 字要占满画面（2026-10-10 加，为让视频端照抄得准）**：纸张类道具**正俯视平铺、纸面占满整个画面**，字号要大到笔画清晰可辨 —— 视频生成时 H3 是从这张图学"字长什么样"，字太小就必错
  - **背面必须是空白纸背**：写死「纸张不透光，背面是空白纸背，不透出正面任何字迹、表格线与印章」。不写就会出现"正面有字、背面也能看到内容"的透光穿帮（实测）
  - 禁写「纸张很薄／半透明／能透出」

## 生成规则

- 以道具 `name`（名称）与 `description`（物品外貌）为核心：材质、颜色、形状、大小、新旧程度、磨损痕迹等物理细节**逐项落地**，这是道具辨识度的来源
- **单张内道具居中完整呈现**，四周留白，比例准确、边缘完整，不要裁切道具主体
- **文字 / 图案占满画面、清晰锐利**：这是道具图存在的首要理由（视频端要靠它照抄）
- 柔和均匀的影棚光，阴影轻淡，高细节
- 只描写物品本身，不要提及剧情、角色或用途（背景与画面都不承载叙事内容）
- 输出使用会话语言指令指定的目标语言，不要混入无关词汇；**不要**"电影质感"类词汇（道具图是产品图不是剧照）

## 禁止事项

- **手部持握（手指、手掌、手臂、任何持握姿态）、人物**
- 其他物品、包装、底座、展示架（除非它就是道具本体的一部分）、场景环境入镜
- **多角度拼图 / 三联板 / 分格**（2026-10-10 起明确禁止 —— 会让模型分不清标准视角）
- 水印、签名（道具本体上印刷的文字按上面「画面内文字」规则**逐字写明**，可以保留并描述）
- 环境反光、彩色光
- 夸张透视、变形、比例失真、边缘裁切

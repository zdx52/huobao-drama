# 道具最终提示词（三联参考板 · 白底单品）

生成的是一张**三联参考板**（横向三格，同一道具的三个角度），**不是单张产品图**：

| 格 | 位置 | 内容 | 治什么 |
|---|---|---|---|
| **格① 主视角** | 左侧大格（约 55% 宽）| 扁平道具（纸张/证件/照片）= **正俯视平铺**；立体道具 = **微俯视 3/4 正面** | **文字与比例的唯一清晰来源**，给足像素 |
| **格② 侧视** | 右上小格 | 同一道具的 **3/4 侧视角**，近大远小透视 | **几何一致性** —— 卡必须见过"倾斜角度长什么样"；**格② 仍只画道具本身，不画手持** |
| **格③ 第三视角** | 右下小格 | **扁平道具**（纸张/证件/照片）= **空白纸背**；**圆柱/长条道具**（香烟/笔/瓶/刀）= **从另一端看**（换一头，把正面看不到的那一端放进画面，两端形态都要清楚）；**块状立体道具**（杯子/工具）= **背面或底面视角** | 防"正面字透到背面"的穿帮；防"圆柱体被当成有正反面的平面"而画丢一端 |

**为什么必须三联**：单张白底正俯视图与视频里的使用场景**几何冲突**（俯视平摊 vs 手持倾斜、白底 vs 场景光、占满画布 vs 场景中小物体），模型必须"重画"才能塞进场景 → **文字和大小一起走样**（2026-10-09 实测：报到单文字与纸张尺寸都对不上参考图）。三联板让 RefMod 卡与参考图同时看到三个角度，模型无需重画。

三条硬性要求（三格都适用）：
1. **物品各部分比例准确**——不要夸张、变形或风格化拉伸，道具的相对尺寸关系必须真实
2. **边缘完整**——道具整体完整入镜，四周留白，任何部分都不得被画面边缘裁切
3. **背景不承载任何叙事内容**——纯白背景只是衬底，不带场景感、不带情节暗示、不带装饰元素
4. **每一格画面里只有这一个道具**——除纯白背景与它自身的轻淡阴影外，**不得出现任何其他东西**：人物、**手（任何形式的持握/手指/手掌/手臂）**、其他物品、包装、底座、展示架、场景环境。**三格全部适用，格②（侧视）也不许画手持** —— 参考图只提供"这个道具斜着长什么样"的角度样本，**持握状态由视频自己生成，绝不由参考图给出**

## 输出结构（按此顺序组装，语言跟随会话语言指令）

```
三联参考板，横向构图，纯白背景，三个分区由 6 像素纯白细线整齐分隔，
无边框、无标注文字、无箭头、无编号，画面中不出现任何额外文字：
【左侧大格，约占画面左侧 55% 宽度】单品产品图，标准产品摄影视角，[格①视角：
扁平道具写"正俯视平铺，平摊占满本格"；立体道具写"微俯视 3/4 正面"]，
[道具名 + 材质/颜色/形状/大小 + 新旧程度与磨损细节]，
[若有文字：按「画面内文字」规则逐字写在本格]，
物品各部分比例准确，孤立放置在纯白背景上，居中完整入镜，边缘完整无裁切；
【右上小格】同一道具的 3/4 侧视角，[透视与立体感描述]，
同一材质、同一颜色、同一磨损痕迹、同一比例，纯白背景，边缘完整无裁切；
【右下小格】[扁平道具：同一道具的纯白空白纸背，纸张不透光，不透出正面任何
字迹、表格线与印章；圆柱/长条道具：同一道具从另一端看的视图，[点名那一端是什么，
如「烟丝端切口，可见烟丝纹理」「笔尖」「瓶底」]，两端形态都要清楚、与本格一致；
块状立体道具：同一道具的背面或底面视角]，纯白背景，边缘完整无裁切；
三个分区必须是同一道具：完全相同的尺寸比例、材质、颜色、磨损痕迹，只是拍摄角度不同。
背景纯净不承载任何叙事内容，无其他物品、无人物、无场景、无手部持握，
柔和均匀的影棚光，轻淡阴影，高细节
```

## 画面内文字（硬性规则）

**道具本体上的文字必须逐字写出**——包装正面字、标签、书名、印章字样、刻字、铭牌数字。不写具体文字、只说"表面有文字"，模型必然乱码。

- **有字**：用引号把原文框住，写明位置（如 `包装正面印着"云南白药"四个字`、`封皮上竖排写着"春秋"二字`）
  - **只写短的**：中文 ≤6 字、英文/数字 ≤2 个词
  - 文字来源**逐字照抄**资产 `name`／`description` 里已有的文字，**禁止改写、禁止自己编**；`description` 没写但道具必然有字（如书名）→ 按小说情景给出最简写法
- **无字**：明确写「道具表面没有任何文字」，**不许留白让模型自由发挥**
- **禁止**："表面有一些文字" / "包装上有汉字" 这类不给具体文字的写法
- **纸张/证件类（单据、证件、信纸、报纸、书页、照片）另有三条硬性**：
  - **内容要编全**：标题（大字）+ 正文 2~4 行 + 落款（人名/日期）+ 印章（章内的字），**各成一组、逐字写死**。例：`纸面竖排写着"报到证"三个大字；下方正文三行分别写着"林巧""红星机械厂""二车间钳工"；右下角落款"三月十七日"；一枚红色圆章，章内写着"红星机械厂"`——纸面很大，只写一个标题会显得空旷简陋，更容易被模型留白
  - **背面必须是空白纸背**：写死「纸张不透光，背面是空白纸背，不透出正面任何字迹、表格线与印章」。不写就会出现"正面有字、背面也能看到内容"的透光穿帮（实测）
  - 禁写「纸张很薄／半透明／能透出」

## 生成规则

- 以道具 `name`（名称）与 `description`（物品外貌）为核心：材质、颜色、形状、大小、新旧程度、磨损痕迹等物理细节**逐项落地**，这是道具辨识度的来源。**这些物理细节必须在三格里完全一致**
- **三格各自视角**：格① 扁平道具用正俯视平铺（文字最清楚），立体道具用微俯视 3/4 正面；格② 一律 3/4 侧视角带透视；格③ **按形状分三档**（扁平=空白纸背；圆柱/长条=从另一端看；块状立体=背面/底面视角）。**格② 不能省** —— 视频里道具处于手持/倾斜的**使用状态**，卡必须见过"倾斜角度"的样本才锁得住；**但格② 里同样只画道具本身、单独悬置于纯白背景上，绝不画手、绝不画人物、绝不画任何持握姿态**（持握由视频生成，参考图只提供角度样本）
- **圆柱 / 长条道具禁止写「背面」「纸背」「翻转后的另一面」**：圆柱体没有正反面，模型会把这类词理解成"把一张纸翻过去"，结果**画丢一端**（2026-10-10 实测：香烟的格③画成了没有滤嘴的一段）。**改写为「从另一端看」并点名那一端是什么**（烟丝端 / 笔尖 / 瓶底 / 刀背），并写明「两端形态都要清楚」
- 单格内道具居中完整呈现，四周留白，比例准确、边缘完整，不要裁切道具主体
- 三格由 6 像素纯白细线分隔，**板上不许出现任何标注文字、格名、箭头、编号**（会被模型当成画面里的文字渲染出来）
- 柔和均匀的影棚光，阴影轻淡，高细节；三格光线一致
- 只描写物品本身，不要提及剧情、角色或用途（背景与画面都不承载叙事内容）
- 输出使用会话语言指令指定的目标语言，不要混入无关词汇；**不要**"电影质感"类词汇（道具图是产品图不是剧照）

## 禁止事项

- **手部持握（手指、手掌、手臂、任何持握姿态）、人物** —— 三格全部适用，**尤其格② 侧视格**
- 其他物品、包装、底座、展示架（除非它就是道具本体的一部分）、场景环境入镜
- 水印、签名（道具本体上印刷的文字按上面「画面内文字」规则**逐字写明**，可以保留并描述）
- 环境反光、彩色光
- 夸张透视、变形、比例失真、边缘裁切

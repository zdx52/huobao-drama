# 소품 최종 프롬프트(삼연 레퍼런스 시트 · 화이트 배경 단품)

생성물은 **삼연 레퍼런스 시트**(가로 3분할, 같은 소품의 세 각도)이며, **단품 이미지 한 장이 아닙니다**:

| 패널 | 위치 | 내용 | 해결하는 문제 |
|---|---|---|---|
| **① 주시점** | 왼쪽 큰 패널(폭 약 55%) | 평평한 소품(종이·신분증·사진)=**정면 위에서 내려다보는 평면 배치**; 입체물=**약간 위에서 내려다보는 3/4 정면** | **문자와 비율의 유일한 고해상도 원천** |
| **② 측면** | 우상단 작은 패널 | 같은 소품의 **3/4 각도**, 근대원소 원근 | **기하학적 일관성** — 카드가 "기울어진 각도"를 본 적이 있어야 함; **패널 ② 도 소품만 그리고 손은 그리지 않음** |
| **③ 세 번째 각도** | 우하단 작은 패널 | **평평한 소품**(종이·신분증·사진)=**빈 종이 뒷면**; **원통·길쭉한 소품**(담배·펜·병·칼)=**반대쪽 끝에서 본 모습**(방향을 돌려 앞면에서 안 보이던 끝을 화면에 넣기; 양쪽 끝 형태가 모두 판별 가능해야 함); **덩어리 입체물**(컵·공구)=**뒷면 또는 밑면 시점** | 앞면 문자가 뒷면으로 비치는穿幫 방지 + "원통을 앞뒤가 있는 평면으로 취급"해 한쪽 끝이 사라지는 오류 방지 |

**왜 3장이어야 하는가**: 흰 배경 정면 위 이미지는 영상의 사용 장면과 **기하학적으로 충돌**한다(정면 평면 vs 손에 기울어진 들기, 흰 배경 vs 장면 조명, 화면 전체 vs 장면 속 작은 물건) → 모델이 장면에 맞추기 위해 **다시 그리게 되고** → **문자와 크기가 함께 어긋난다**(2026-10-09 실측: 전표의 문자와 종이 크기가 레퍼런스와 불일치). 삼연 시트면 RefMod 카드와 레퍼런스 이미지가 세 각도를 동시에 보므로 모델이 다시 그리지 않아도 된다.

세 가지 엄격한 요구 사항(세 패널 모두 적용):
1. **물건 각 부분의 비율이 정확할 것** — 과장, 변형 또는 스타일화된 늘이기 금지. 소품의 상대적 크기 관계가 실제와 같아야 합니다
2. **가장자리가 완전할 것** — 소품 전체가 온전히 화면에 들어오고 사방에 여백을 두며, 어떤 부분도 화면 가장자리에 잘리지 않아야 합니다
3. **배경이 어떤 서사 내용도 담지 않을 것** — 순백 배경은 받침일 뿐, 장면감·줄거리 암시·장식 요소를 갖지 않습니다
4. **각 패널의 화면에는 이 소품만 등장한다** — 순백 배경과 소품 자체의 옅은 그림자 외에는 **아무것도 나타나지 않는다**: 인물, **손(잡기·손가락·손바닥·팔 등 어떤 형태든)**, 다른 물건, 포장, 받침대, 진열대, 장면 환경. **세 패널 모두 적용, 패널 ②(측면)에서도 손에 쥔 묘사를 금지** — 레퍼런스가 제공하는 것은 "기울어진 각도의 샘플"뿐이며, **잡힌 상태는 영상이 생성하는 것이고 레퍼런스에서 절대 나오지 않는다**

## 출력 구조(이 순서대로 하나의 연결된 문장으로 조립, 언어는 세션 언어 지시를 따름)

```
삼연 레퍼런스 시트, 가로 구도, 순백 배경, 세 구역은 6픽셀 순백 얇은 선으로 깔끔하게 구분,
테두리 없음, 라벨 텍스트 없음, 화살표 없음, 번호 없음, 화면 중 어디에도 여분의 텍스트 없음:
【왼쪽 큰 패널(폭 약 55%)】단품 제품 이미지, 표준 제품 사진 시점, [① 시점:
평평한 소품 → "정면 위에서 내려다보는 평면 배치, 이 패널을 가득 채움";
입체물 → "약간 위에서 내려다보는 3/4 정면"],
[소품명 + 재질/색상/형태/크기 + 사용감과 마모 디테일],
[문자가 있는 경우: 이 패널에 원문을 따옴표로 감싸 문자 그대로 기재],
물건 각 부분의 비율이 정확, 순백 배경 위에 고립, 중앙에 온전히 들어오고 가장자리가 완전하여 잘림 없음;
【우상단 패널】같은 소품의 3/4 각도, [원근과 입체감 서술],
같은 재질, 같은 색, 같은 마모, 같은 비율, 순백 배경, 가장자리 완전, 잘림 없음;
【우하단 패널】[평평한 소품: 같은 소품의 순백 빈 종이 뒷면, 종이는 빛을 투과시키지 않으며
앞면의 문자·표줄·인을 전혀 비치지 않음 / 원통·길쭉한 소품: 같은 소품을 반대쪽 끝에서 본 모습,
[그 끝을 명시. 예: "담배 잎 담배쪽 절단면", "펜촉", "병 바닥"], 양쪽 끝 형태가 판별 가능하고
이 패널과 일치할 것 / 덩어리 입체물: 같은 소품의 뒷면 또는 밑면 시점], 순백 배경, 가장자리 완전, 잘림 없음;
세 구역은 반드시 같은 소품: 크기 비율·재질·색·마모가 완전히 일치하고, 촬영 각도만 다름.
배경은 깨끗하고 어떤 서사 내용도 담지 않으며, 다른 물건 없음, 인물 없음, 장면 없음,
손에 쥔 모습 없음, 부드럽고 고른 스튜디오 조명, 옅은 그림자, 고디테일
```

## 생성 규칙

- 소품 `name`(이름)과 `description`(물건의 외형)을 핵심으로 합니다: 재질, 색상, 형태, 크기, 사용감, 마모 흔적 등 물리적 디테일을 **항목별로 모두 구체화**합니다 — 이것이 소품 식별도의 원천이며, **이 물리적 디테일은 세 패널 모두에서 완전히 일치해야 합니다**
- **패널별 시점**: 패널 ① 은 평평한 소품에 정면 위 평면 배치(문자가 가장 선명), 입체물에 약간 위에서 내려다보는 3/4 정면; 패널 ② 는 항상 3/4 측면+원근; 패널 ③ 은 항상 뒷면(평평=빈 종이 뒷면, 입체=뒷면 시점). **패널 ② 를 생략해서는 안 됩니다** — 영상 속 소품은 손에 잡힌·기울어진 **사용 상태**에 있으므로, 카드가 "기울어진 각도" 샘플을 갖지 못하면 잠그지 못합니다; **다만 패널 ② 에서도 소품 자체만 순백 배경 위에 단독으로 띄워 그리고, 손·인물·어떤 잡기 자세도 절대 그리지 않는다**(잡기는 영상이 생성하고, 레퍼런스는 각도 샘플만 제공한다)
- **원통·길쭉한 소품에 "뒷면" "종이 뒷면" "뒤집은 면"이라고 쓰는 것을 금지**: 원통에는 앞뒤가 없고, 모델은 이 말을 "종이를 뒤집는다"로 해석해 **한쪽 끝을 놓친다**(2026-10-10 실측: 담배 패널 ③에 필터가 없이 나옴). **"반대쪽 끝에서 본 모습"으로 바꿔 쓰고 그 끝을 명시**하며(담배 잎쪽／펜촉／병 바닥／칼등), "양쪽 끝 형태가 모두 판별 가능할 것"을 함께 적는다
- 각 패널 안에서 소품을 중앙에 온전히 배치하고 사방에 여백을 둡니다. 비율 정확, 가장자리 완전, 본체를 자르지 마세요
- 세 패널은 6픽셀 순백 얇은 선으로 구분하며, **시트에 라벨 텍스트·패널 이름·화살표·번호를 일절 넣지 마세요**(모델이 화면 내 텍스트로 그려 버림)
- 부드럽고 고른 스튜디오 조명, 옅은 그림자, 고디테일. 세 패널의 조명은 동일
- 물건 자체만 묘사하고, 줄거리·캐릭터·용도를 언급하지 마세요(배경과 화면 모두 서사 내용을 담지 않음)
- 출력은 세션 언어 지시가 지정한 목표 언어를 사용하고, 무관한 어휘를 섞지 마세요; "영화적 질감"류의 단어는 쓰지 **마세요**(소품 이미지는 제품 사진이지 스틸컷이 아님)

## 금지 사항

- **손에 쥔 모습(손가락·손바닥·팔·어떤 잡기 자세든), 인물** — 세 패널 모두 적용, **특히 패널 ②(측면)**
- 다른 물건, 포장, 받침대, 진열대(소품 본체의 일부인 경우 제외), 장면 환경이 화면에 들어오는 것
- 텍스트, 워터마크, 서명(소품 본체에 인쇄된 글자·무늬는 유지하고 묘사 가능)
- 환경 반사광, 컬러 조명
- 과장된 원근, 변형, 비율 왜곡, 가장자리 잘림

## 저장

`save_prop_final_prompt` 를 호출합니다: prompt 파라미터에는 스타일 단어를 넣지 않습니다. **프로젝트 비주얼 스타일은 도구가 최종 프롬프트 맨 앞에 자동으로 주입합니다**.

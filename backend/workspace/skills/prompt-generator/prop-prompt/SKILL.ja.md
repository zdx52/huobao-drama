# 小道具最終プロンプト（三連参考シート · 白背景単品）

生成するのは**三連参考シート**（横向き3分割、同一小道具の3アングル）で、**単品画像1枚ではない**：

| 欄 | 位置 | 内容 | 解決する問題 |
|---|---|---|---|
| **① 主視点** | 左の大欄（幅の約55%）| 扁平な小道具（紙・証明書・写真）＝**真上からの平置き**；立体物＝**やや俯瞰の3/4正面** | **文字と比率の唯一の高解像度源** |
| **② 側面** | 右上の小欄 | 同一小道具の**3/4アングル**、近大遠小の透視 | **幾何的一貫性** — カードが「傾いた角度」を見たことが必要；**欄② も小道具だけを描き、手持ちは描かない** |
| **③ 背面** | 右下の小欄 | 扁平物＝**空白の紙の裏**；立体物＝**背面視点** | 表面の文字が裏から透ける穿幫を防止 |

**なぜ3枚必要か**：白背景の真上画像は映像内の使用シーンと**幾何的に衝突する**（真上平置き vs 手に傾けて保持、白背景 vs シーン光、全面積 vs シーン中の小物）ため、モデルはシーンに収めるために**書き直す**必要があり → **文字と大きさが同時に狂う**（2026-10-09 実測：伝票の文字と紙の寸法が参考画像と一致せず）。三連シートならRefModカードと参考画像が3アングルを同時に見て、モデルは書き直さずに済む。

3つの硬性要件（3欄すべてに適用）：
1. **物品の各部の比率が正確**——誇張、変形、様式化された引き伸ばしをしない。小道具の相対的なサイズ関係は実際どおりでなければならない
2. **輪郭が完全**——小道具全体が完全に画面に収まり、四方に余白を残す。どの部分も画面の端で裁切してはならない
3. **背景はいかなる物語的内容も担わない**——純白の背景はあくまで下地であり、シーン感を帯びず、プロットの暗示を持たず、装飾要素を含まない
4. **各欄の画面にはこの小道具だけが映る**——純白の背景と小道具自身の淡い影以外に、**いかなるものも映さない**：人物、**手（あらゆる保持・指・手のひら・腕の描写）**、他の物品、包装、台座、ディスプレイスタンド、シーン環境。**3欄すべてに適用し、欄②（側面）でも手で持つ描写は禁止** —— 参考画像が提供するのは「傾いた角度のサンプル」だけであり、**保持状態は映像側が生成するもので、参考画像からは絶対に出さない**

## 出力構造（この順序で1段落の連続した記述を組み立てる。言語はセッションの言語指令に従う）

```
三連参考シート、横向き構図、純白背景、3つの分区は6ピクセルの純白の細い罫線で整然と区切り、
枠なし、ラベル文字なし、矢印なし、番号なし、画面中にいかなる余分な文字も出現させない：
【左の大欄（幅の約55%）】単品プロダクト画像、標準的なプロダクト撮影の視点、[①の視点：
扁平物は「真上からの平置き、この欄いっぱいに広げる」／立体物は「やや俯瞰の3/4正面」]、
[小道具名 ＋ 材質／色／形状／大きさ ＋ 新旧の度合いと摩耗の細部]、
[文字がある場合は：この欄に原文を引用符で囲んで逐字で記載]、
物品の各部の比率は正確、純白の背景上に孤立、中央に完全に収まり、輪郭は完全で裁切なし；
【右上の小欄】同一小道具の3/4アングル、[透視と立体感の記述]、
同一の材質・同一の色・同一の摩耗・同一の比率、純白背景、輪郭は完全で裁切なし；
【右下の小欄】同一小道具の背面[扁平物：純白の空白の紙の裏、紙は光を通さず、
表面の文字・罫線・印章を一切透かさない／立体物：背面視点]、純白背景、輪郭は完全で裁切なし；
3つの分区は必ず同一の小道具：寸法比率・材質・色・摩耗は完全に一致し、撮影アングルだけが異なる。
背景は無垢でいかなる物語的内容も担わない、他の物品なし、人物なし、シーンなし、手で持つ描写なし、
柔らかく均一なスタジオ光、淡い影、高精細
```

## 生成ルール

- 小道具の `name`（名称）と `description`（物品の外観）を中核とする：材質、色、形状、大きさ、新旧の度合い、摩耗の跡などの物理的な細部を**一項目ずつ漏れなく落とし込む**。これが小道具の識別性の源となる。**これらの物理的細部は3欄すべてで完全に一致させること**
- **各欄の視点**：欄① は扁平物に真上からの平置き（文字が最も鮮明）、立体物にやや俯瞰の3/4正面；欄② は常に3/4側面＋透視；欄③ は常に背面（扁平＝空白の紙の裏、立体＝背面視点）。**欄② を省略してはならない** — 映像内では小道具は手持ち・傾斜の**使用状態**にあるため、カードが「傾いた角度」のサンプルを持たないとロックできない；**ただし欄② でも小道具そのものだけを純白背景上に単独で浮かせて描き、手・人物・あらゆる保持姿勢は絶対に描かない**（保持は映像が生成し、参考画像は角度サンプルのみを提供する）
- 各欄内で小道具を中央に完全に呈示し、四方に余白を残す。比率は正確、輪郭は完全。主体を裁切しない
- 3欄は6ピクセルの純白の細い罫線で区切り、**シート上にラベル文字・欄名・矢印・番号を一切出さない**（モデルが画面内の文字として描き出してしまう）
- 柔らかく均一なスタジオ光、影は淡く、高精細。3欄の光は同一
- 物品そのものだけを描写し、プロット、キャラクター、用途に言及しない（背景も画面も物語的内容を担わない）
- 出力はセッションの言語指令で指定されたターゲット言語を使い、無関係な語彙を混ぜない。**「映画の質感」類の語彙は使わない**（小道具画像は劇中スチルではなくプロダクト画像である）

## 禁止事項

- **手で持つ描写（指・手のひら・腕・あらゆる保持姿勢）、人物** — 3欄すべてに適用、**特に欄②（側面）**
- 他の物品、包装、台座、ディスプレイスタンド（それが小道具本体の一部である場合を除く）、シーン環境の写り込み
- 文字、透かし、署名（小道具本体に印刷された文字や図柄は残し、描写してよい）
- 環境の反射、カラーの光
- 誇張されたパース、変形、比率の歪み、輪郭の裁切

## 保存

`save_prop_final_prompt` を呼び出す：prompt パラメータにスタイル語を含めない。**プロジェクトのビジュアルスタイルはツールが最終プロンプトの先頭へ自動注入する**。

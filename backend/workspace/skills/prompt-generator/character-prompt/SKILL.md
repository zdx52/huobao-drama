# 角色参考板（一帧四格：脸部特写 / 正面 / 左侧面 / 背面，三视图均有头）

生成的是一张角色参考板（reference board），**一帧画面、四个竖版画格，从左到右排列**，每格职责单一：

- **格 1：脸部特写（最左）**——胸部以上的正面免冠证件照式构图，**是整张参考板的身份锚点**
- **格 2：正面全身（有头）**——正面站姿全身，头正对镜头，能看到脸、发型、整套服装与体型
- **格 3：左侧面全身（有头）**——90 度正左侧面，鼻尖朝画面左边，用于校核侧面轮廓、发长与侧身形
- **格 4：背面全身（有头）**——背面站姿全身，用于校核后脑发型、背身服装与体态

**为什么这样分**：身份由 **RefMod 卡**（从本板抽取）与"脸部特写格"共同锁定，**不需要再靠无头格防串脸**；三视图全部保留头部，是为了让体型、发型（含侧面/后面的长度与轮廓）和服装一起进卡——实测**整板抽卡**的效果明显好于只喂脸格。脸部特写放最左，是让身份锚点排在最前。

**核心原则：一致性 > 美观。** 这张图是后续所有角色图片、视频参考的形象锚点，必须中性、清晰、可复用——不要追求单张图的艺术感。

## 描述顺序规则

把**最有辨识度的特征放在前面**，按此顺序落地 `appearance`（样貌）与 `styling`（妆造）的每个关键元素，不遗漏：

1. 身份锚点：年龄感（如"二十出头"）、性别感、体态（高矮胖瘦、姿态习惯）
2. 人种锁定（防串脸第一条）：中国故事角色必须写明"东亚人面孔"并给东亚五官特征（如单眼皮/内双、宽鼻翼、黑眼睛黄皮肤），严禁用"深邃眼窝、高鼻梁、立体五官"这类欧美脸词汇——模型默认偏欧美脸，不锁必飘
3. 五官：脸型、眼睛、其他显著特征（疤、痣、眼镜等）——脸部特写尤其依赖这部分描写
4. 发型：颜色、长度、样式（长度和发尾形状要能被侧视格、背视格同时校核）
5. 服装：款式、颜色、材质、状态（如"袖口有焊锡痕迹的皱褶工服"）
6. 配饰：只写有辨识度的，不堆砌

角色的性格特点要转化为外在气质与神态描写（如"憔悴" → "眼神疲惫、肩膀微垮"），不要直接出现性格词汇。

## 构图与一致性

- **画格数固定四格，顺序固定：格1脸部特写（最左）→ 格2正面全身 → 格3左侧面全身 → 格4背面全身**，不得调换、不得增删
- **脸部特写必须放在最左（格 1）**——这是身份锚点，用于后端裁切出独立的脸部参考图，并向 RefMod 卡提供身份
- **三视图一格不少、一律有头**：格2/3/4 都必须画出头部（脸、发型、耳朵、后脑按视角如实出现），**不再使用无头处理**；禁止出现"无头""头部被移除""颈部断口""人台"这类写法与效果
- **侧面格固定为左侧面，只用一句画面语言定朝向**：写"**90 度正左侧面，鼻尖朝画面左边**"。**不要同时再写"从人物左侧拍摄""左侧身朝前"这类第二个方向词**——两个方向词并存，模型会理解成转身的左侧四分之三侧；可见部位改用列举写（近侧是左肩、左臂、左侧裤线）。**不许出现右侧面**，每次朝向必须一致（否则跨图对齐会左右反）
- 格 1 脸部特写：**只画头部到肩颈**（等同 1 寸证件照构图），**不出现胸部以下、不出现手、不出现全身**——特写变大头像就是不合格
- **脸部特写必须头正对镜头、脖子端正**：明确写出"头部正对镜头、不偏转、脸面左右对称、双耳等高、下巴水平、视线平视镜头"——歪头会让脸部辨识锚点失效，后续所有视频参考都跟着歪
- **四格服装必须是同一件**：领口形状、颜色、纽扣、面料磨损状态逐项对齐，外套/内搭/裤/鞋逐件一致
- **整张参考板只允许这一个角色**：不得出现第二个人物、不得出现重复的同一个人
- **脸部只以格 1 为准**：写提示词引用本板时，若镜头需要看脸，点名"**脸部特写格**"；后三格只提供体型、服装、发型的多视角信息
- 中性站姿、自然表情——方便作为参考图复用
- 柔和均匀的棚拍光，不要戏剧性光影（参考图要在各种场景下都能用）
- 输出使用会话语言指令指定的目标语言，不要混入无关词汇

## 禁止事项

- 动态姿势、夸张表情、手持道具、与他人同框
- **无头 / 头部被移除 / 颈部断口 / 人台**（新规范三视图必须有头；出现任意一处 = 不合格，必须重出）
- **歪头/侧脸/仰头/低头/斜肩/身体偏心**（脸部特写只认正对镜头的头位）。审图时若格 1 的头部轴向与画面垂直轴夹角超过约 5°，即判不合格，必须重出
- **格 1 超出头肩范围**（出现胸部以下、手、全身 = 不合格，必须重出）
- **四格服装不一致**（颜色/款式/领口/纽扣不同 = 不合格，必须重出）
- **侧面格出现右侧面 / 四分之三侧 / 转身半侧**（必须是鼻尖朝画面左边的 90 度正侧面，任意偏离 = 不合格，必须重出）
- **出现第五格、拼贴、并排多组、画格顺序错乱**（必须正好四格且顺序为 脸 / 正 / 左侧 / 背）
- 裁切身体（格 2/3/4 必须脚底完整入镜；格 1 必须头顶到肩线完整入镜）
- 文字、标签、水印、签名
- 重阴影、彩色背景光、背景道具

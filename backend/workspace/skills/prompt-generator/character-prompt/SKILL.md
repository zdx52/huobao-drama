# 角色参考板（一帧四格：无头正视 / 左侧视 / 背视 + 脸部特写）

生成的是一张角色参考板（reference board），**一帧画面、四个竖版画格，从左到右排列**，每格职责单一：

- **格 1：正面全身，头部被干净地移除**——只有肩、躯干、手臂、腿、鞋与整套服装，画面里没有头
- **格 2：左侧面全身，头部被干净地移除**——90 度正左侧面（从人物左侧拍、人物面朝画面左侧），只有肩线以下的左侧身服装与体态
- **格 3：背面全身，头部被干净地移除**——只有后颈以下的背身服装与体态
- **格 4：脸部特写**——胸部以上的正面免冠证件照式构图，**是整张参考板唯一的面部来源**

**为什么这样分**：行业做法是"脸部图定是谁、服装图定穿什么"，脸部只留一处锚点，模型才不会拿多张脸互相打架导致串脸。脸放在最右（末格）是行业标准配方（3 格版即 无头正 / 无头背 / 脸部特写），无头格在前、脸在最后。

**核心原则：一致性 > 美观。** 这张图是后续所有角色图片、视频参考的形象锚点，必须中性、清晰、可复用——不要追求单张图的艺术感。

## 描述顺序规则

把**最有辨识度的特征放在前面**，按此顺序落地 `appearance`（样貌）与 `styling`（妆造）的每个关键元素，不遗漏：

1. 身份锚点：年龄感（如"二十出头"）、性别感、体态（高矮胖瘦、姿态习惯）
2. 人种锁定（防串脸第一条）：中国故事角色必须写明"东亚人面孔"并给东亚五官特征（如单眼皮/内双、宽鼻翼、黑眼睛黄皮肤），严禁用"深邃眼窝、高鼻梁、立体五官"这类欧美脸词汇——模型默认偏欧美脸，不锁必飘
3. 五官：脸型、眼睛、其他显著特征（疤、痣、眼镜等）——脸部特写尤其依赖这部分描写
4. 发型：颜色、长度、样式
5. 服装：款式、颜色、材质、状态（如"袖口有焊锡痕迹的皱褶工服"）
6. 配饰：只写有辨识度的，不堆砌

角色的性格特点要转化为外在气质与神态描写（如"憔悴" → "眼神疲惫、肩膀微垮"），不要直接出现性格词汇。

## 构图与一致性

- **画格数固定四格，顺序固定：格1正面全身 → 格2左侧面全身 → 格3背面全身 → 格4脸部特写**（脸在最右），不得调换、不得增删
- **侧面格固定为左侧面**：必须写"90 度正左侧面、从人物左侧拍摄、人物面朝画面左侧"，**不许出现右侧面**；每次生成朝向必须一致（否则跨图对齐会左右反）
- **无头三格必须用"头部被干净地移除"这个措辞**（英文对应 head cleanly removed）。这是行业里被验证过的说法。**不要用"无头""不要头""颈部裁切""画面外裁切""人台"这些写法**——实测这些写法模型照旧画头
- 无头三格：**画面里不出现脸、五官、头发、后脑、耳朵、帽子，也不要有颈部断口**（颈部以上直接是背景色）
- 格 4 脸部特写：**只画头部到肩颈**（等同 1 寸证件照构图），**不出现胸部以下、不出现手、不出现全身**——特写变大头像就是不合格
- **脸部特写必须头正对镜头、脖子端正**：明确写出"头部正对镜头、不偏转、脸面左右对称、双耳等高、下巴水平、视线平视镜头"——歪头会让脸部辨识锚点失效，后续所有视频参考都跟着歪
- **格 4 与格 1 格 2 格 3 的服装必须是同一件**：领口形状、颜色、纽扣、面料磨损状态逐项对齐，外套/内搭/裤/鞋逐件一致
- **整张参考板只允许一处面部**：只有格 4 有脸，格 1 格 2 格 3 一律无头
- 中性站姿、自然表情——方便作为参考图复用
- 柔和均匀的棚拍光，不要戏剧性光影（参考图要在各种场景下都能用）
- 输出使用会话语言指令指定的目标语言，不要混入无关词汇

## 禁止事项

- 动态姿势、夸张表情、手持道具、与他人同框
- **歪头/侧脸/仰头/低头/斜肩/身体偏心**（脸部特写只认正对镜头的头位）。审图时若格 4 的头部轴向与画面垂直轴夹角超过约 5°，即判不合格，必须重出
- **格 4 超出头肩范围**（出现胸部以下、手、全身 = 不合格，必须重出）
- **格 1 格 2 格 3 出现任何头部痕迹**（脸、五官、头发、后脑、耳朵、帽子、颈部断口，任意一处 = 不合格，必须重出）
- **格 4 与格 1 格 2 格 3 的服装不一致**（颜色/款式/领口/纽扣不同 = 不合格，必须重出）
- **侧面格出现右侧面 / 四分之三侧 / 转身半侧**（必须是 90 度正左侧面，任意偏离 = 不合格，必须重出）
- **出现第五格、拼贴、并排多组、画格顺序错乱**（必须正好四格且顺序为 正 / 左侧 / 背 / 脸）
- 裁切身体（格 1 格 2 格 3 必须脚底完整入镜；格 4 必须头顶到肩线完整入镜）
- 文字、标签、水印、签名
- 重阴影、彩色背景光、背景道具

## 保存

调用 `save_character_final_prompt`：prompt 参数不含风格词，**项目视觉风格由工具自动注入到最终提示词的最前方**。

**收尾自检（必须做）**：保存前逐字核对 prompt 里六段硬约束都在——① 一帧四格，顺序为 格1正面全身 / 格2左侧面全身 / 格3背面全身 / 格4脸部特写（脸在最右），没有第五格；② 侧面格写的是"**90 度正左侧面、从人物左侧拍摄、人物面朝画面左侧**"（不是右侧面）；③ 无头三格措辞用的是"**头部被干净地移除**"（不是"无头/颈部裁切/画面外"）；④ 脸部特写限幅："只画头部到肩颈、等同 1 寸证件照构图、不出现胸部以下、不出现手、不出现全身"；⑤ 头位锁："头部正对镜头不偏转、脸面左右对称、双耳等高、下巴水平、视线平视镜头"；⑥ 服装一致："格4肩部露出的衣领、面料颜色与款式，与格1格2格3的上衣是同一件"。缺任意一段就是没按规范生成，补上再保存。

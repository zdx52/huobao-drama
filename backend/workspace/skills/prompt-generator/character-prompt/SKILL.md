# 角色最终提示词（左侧正脸特写 + 右侧三视图）

生成的是一张角色设定参考图（character reference sheet），构图固定为：

- **左侧：正脸特写**——头部与肩部的正面近景，五官、发型、肤质清晰可见，**是整张图唯一的面部来源**
- **右侧：并列展示正面、90 度侧面、背面三张等高全身视图**——同一角色的三个全身视图等高并排；**三张一律从颈部裁切，画面里完全没有头**（无脸、无五官、无头发、无后脑），只展示颈部以下的服装与体态

**核心原则：一致性 > 美观。** 这张图是后续所有角色图片、视频参考的形象锚点，必须中性、清晰、可复用——不要追求单张图的艺术感。

## 输出结构（按此顺序组装单段连贯描述，语言跟随会话语言指令）

```
角色设定参考图，左侧为证件照式正脸特写，右侧并列展示正面、90 度侧面、背面三张等高全身视图，
左侧特写只画头部到肩颈（等同 1 寸证件照构图）：不出现胸部以下、不出现手、不出现全身，头顶到肩线完整入镜，纯白背景，
左侧特写为正面免冠构图：头颈正中、头部正对镜头不偏转、脸面左右对称、双耳等高同时可见、下巴水平、视线平视镜头，
右侧三张全身视图的画面构成：**画面从颈部裁切，头部完全不在画面内**（不是用白色盖住头，而是构图本身就只截取颈部以下，画面上方边缘即肩颈线），
即三张全身视图都看不到头——画面里不存在脸、五官、头发、后脑、耳朵、帽子，只有脖子、肩、躯干、手臂、腿、服装、鞋（发长与发型统一由左侧特写提供），
特写与全身视图都是同一角色，中性 A 字站姿，三张全身视图等高并排、肩线对齐、脚底对齐，
[年龄感 + 性别感 + 体态]，[五官特征]，[发型]，[服装 + 配饰]，
左侧特写肩部露出的衣领、面料颜色与款式，与三张全身视图上的上衣是同一件，领口形状、颜色、纽扣、磨损状态完全一致，
全身视图的服装、体态与左侧正脸特写为同一人，外套/内搭/裤/鞋逐件一致，
纯白背景，柔和均匀的光线，电影质感
```

## 描述顺序规则

把**最有辨识度的特征放在前面**，按此顺序落地 `appearance`（样貌）与 `styling`（妆造）的每个关键元素，不遗漏：

1. 身份锚点：年龄感（如"二十出头"）、性别感、体态（高矮胖瘦、姿态习惯）
2. 人种锁定（防串脸第一条）：中国故事角色必须写明"东亚人面孔"并给东亚五官特征（如单眼皮/内双、宽鼻翼、黑眼睛黄皮肤），严禁用"深邃眼窝、高鼻梁、立体五官"这类欧美脸词汇——模型默认偏欧美脸，不锁必飘
3. 五官：脸型、眼睛、其他显著特征（疤、痣、眼镜等）——正脸特写尤其依赖这部分描写
4. 发型：颜色、长度、样式
5. 服装：款式、颜色、材质、状态（如"袖口有焊锡痕迹的皱褶工服"）
6. 配饰：只写有辨识度的，不堆砌

角色的性格特点要转化为外在气质与神态描写（如"憔悴" → "眼神疲惫、肩膀微垮"），不要直接出现性格词汇。

## 构图与一致性

- 左侧正脸特写：**只画头部到肩颈**（等同 1 寸证件照构图），正面朝向镜头、中性表情、头顶到肩线完整入镜。**不出现胸部以下、不出现手、不出现全身**——特写变大头像就是不合格
- **正脸特写必须头正对镜头、脖子端正**：明确写出"头部正对镜头、不歪头、不侧脸、不倾斜、下巴水平、双耳高度一致"——歪头会让脸部辨识锚点失效，后续所有视频参考都跟着歪
- 右侧三张全身视图：同一角色的正面、90 度侧面、背面，**等高并排、间距均匀**，肩线在同一水平线上、脚底在同一水平线上
- **三张全身视图一律从颈部裁切（画面内完全没有头）**：不是"画个白头盖住"，而是构图本身只从颈部往下取景。画面里不出现脸、五官、头发、后脑、耳朵、帽子。若模型仍画出带头发/头的轮廓，即判不合格重出
- **左侧特写与三张全身视图的服装必须是同一件**：领口形状、颜色、纽扣、面料磨损状态逐项对齐；特写只露肩颈，但露出的衣领/肩部必须和全身视图的上衣完全一致
- 全身视图的服装、体态与左侧特写是同一人——明确写出"全身视图的服装、体态与左侧正脸特写为同一人，外套/内搭/裤/鞋逐件一致"
- 中性站姿、自然表情——方便作为参考图复用
- 柔和均匀的棚拍光，不要戏剧性光影（参考图要在各种场景下都能用）
- 输出使用会话语言指令指定的目标语言，不要混入无关词汇

## 禁止事项

- 动态姿势、夸张表情、手持道具、与他人同框
- **歪头/侧脸/仰头/低头/斜肩/身体偏心**（正脸特写只认正对镜头的头位）。审图时若左侧特写的头部轴向与画面垂直轴夹角超过约 5°，即判不合格，必须重出
- **左侧特写超出头肩范围**（出现胸部以下、手、全身 = 不合格，必须重出）
- **三张全身视图出现任何头部痕迹**（脸、五官、头发、后脑、耳朵、帽子、颈部以上的皮肤轮廓，任意一处 = 不合格，必须重出）
- **左侧特写与全身视图的服装不一致**（颜色/款式/领口/纽扣不同 = 不合格，必须重出）
- 裁切身体（全身视图必须 full body，脚底完整入镜；特写必须头顶到肩线完整入镜）
- 文字、标签、水印、签名
- 重阴影、彩色背景光、背景道具

## 保存

调用 `save_character_final_prompt`：prompt 参数不含风格词，**项目视觉风格由工具自动注入到最终提示词的最前方**。

**收尾自检（必须做）**：保存前逐字核对 prompt 里四段硬约束都在——① 左特写限幅："只画头部到肩颈、等同 1 寸证件照构图、不出现胸部以下、不出现手、不出现全身"；② 头位锁："头部正对镜头不偏转、双耳等高、下巴水平、视线平视镜头"；③ 三视图无头："三张全身视图一律从颈部裁切、画面里不出现脸/五官/头发/后脑/耳朵/帽子"；④ 服装一致："左侧特写肩部露出的衣领、面料颜色与款式，与三张全身视图上的上衣是同一件"。缺任意一段就是没按规范生成，补上再保存。

# 角色参考板（一帧三格三视图：正面 / 左侧面 / 背面，全部完整人物）

生成的是一张角色参考板（reference board），**一帧画面、三个竖版画格，从左到右排列**。三格是同一个人的三视图，**每格都是完整人物：头、脸、五官、发型正常画出，头顶到脚底完整入镜**：

- **格 1：正面全身（最左）**——正对镜头站立，脸清晰可辨、五官可读
- **格 2：左侧面全身**——身体侧身 90 度对着画面左侧，同一人物同一套服装
- **格 3：背面全身**——背身站立（背对镜头），后脑与头发完整画出

**为什么不做「脸部特写格」**：四格版把脸单独做成胸像特写，视频模型会把那张特写当成一个可以复制的镜头，成片开头就出大脸、景别中途跳变。三格全部做成完整全身，脸和身形在同一格里给出，模型没有特写可照抄。

**核心原则：一致性 > 美观。** 这张图是后续所有角色图片、视频参考的形象锚点，必须中性、清晰、可复用——不要追求单张图的艺术感。

## 描述顺序规则

把**最有辨识度的特征放在前面**，按此顺序落地 `appearance`（样貌）与 `styling`（妆造）的每个关键元素，不遗漏：

1. 身份锚点：年龄感（如"二十出头"）、性别感、体态（高矮胖瘦、姿态习惯）
2. 人种锁定（防串脸第一条）：中国故事角色必须写明"东亚人面孔"并给东亚五官特征（如单眼皮/内双、宽鼻翼、黑眼睛黄皮肤），严禁用"深邃眼窝、高鼻梁、立体五官"这类欧美脸词汇——模型默认偏欧美脸，不锁必飘
3. 五官：脸型、眼睛、其他显著特征（疤、痣、眼镜等）
4. 发型：**颜色必写**（如"枯黄染发、发根发黑"）、长度、样式（三格都能看到头发：正面写额前刘海与鬓角，侧面写发尾走向，背面写后脑与发长）
5. 服装：款式、**颜色（每件单品都要给颜色，不许只写"深色"这类含糊词）**、材质、状态（如"袖口有焊锡痕迹的皱褶工服"）
6. 配饰：只写有辨识度的，不堆砌；**写到的配饰必须给颜色或材质**（如"腕上一只细银镯，氧化发暗"）
7. **肤色：色阶 + 明暗必须写**（如"皮肤蜡黄粗糙""肤色健康偏深，颈侧可见晒痕"）——不写肤色，后面生成分镜提示词时无从下笔，成片肤色会飘

🔴 **四项颜色一个都不能少**：**发色、肤色、服装颜色、配饰颜色**是后面所有分镜提示词唯一的颜色来源 —— 生成提示词的模型**看不到图、只能读你写的文字**。这四项没写进卡片文字，成片就只能靠模型自己猜。

角色的性格特点要转化为外在气质与神态描写（如"憔悴" → "眼神疲惫、肩膀微垮"），不要直接出现性格词汇。

## 构图与一致性

- **画格数固定三格，顺序固定：格1正面全身 → 格2左侧面全身 → 格3背面全身**，不得调换、不得增删
- **每格必须是完整人物**：头顶（含头发）到脚底（含鞋）全部在画面内，不许裁头、不许裁脚、不许只画半身或胸像
- **三格景别必须完全一致**：都是全身，人物在各自画格里的高度占比一致，头顶与脚底分别对齐同一水平线
- **侧面格固定为左侧面，只用一句画面语言定朝向**：写"**身体侧身 90 度，对着画面左侧**"，不许出现右侧面；同一段提示词里不要同时再写"从人物左侧拍摄""左侧身朝前"这类第二个方向词
- **正面格必须头正对镜头、脖子端正**：明确写出"头部正对镜头、不偏转、脸面左右对称、双耳等高、下巴水平、视线平视镜头"
- **三格服装必须是同一件**：领口形状、颜色、纽扣、面料磨损状态逐项对齐，外套/内搭/裤/鞋逐件一致
- **三格必须是同一张脸**：脸型、五官、肤色、发色逐项一致；只允许出现同一个人，不得出现第二个人物
- 中性站姿、自然表情——方便作为参考图复用
- 柔和均匀的棚拍光，不要戏剧性光影（参考图要在各种场景下都能用）
- 输出使用会话语言指令指定的目标语言，不要混入无关词汇

## 禁止事项

- **任何一格出现胸像 / 半身 / 特写 / 大头照构图**（三格一律全身）
- **任何一格裁切身体**（头顶到脚底必须完整入镜，含鞋）
- 动态姿势、夸张表情、手持道具、与他人同框
- **歪头/侧脸/仰头/低头/斜肩/身体偏心**（正面格只认正对镜头的头位；格 1 头部轴向与画面垂直轴夹角超过约 5° = 不合格）
- **四格或更多格、拼贴、并排多组、画格顺序错乱**（必须正好三格，顺序为 正 / 左侧 / 背）
- **三格服装不一致**（颜色/款式/领口/纽扣不同 = 不合格）
- **三格不是同一张脸**（发色、肤色、五官不同 = 不合格）
- **侧面格出现右侧面 / 四分之三侧 / 转身半侧**（必须是身体侧身 90 度、对着画面左侧的正侧面）
- 文字、标签、水印、签名
- 重阴影、彩色背景光、背景道具
